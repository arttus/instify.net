# ODUEO Website Design Specification
*Inspired by CaseGen.ai Design Approach*

---

## Design Philosophy

**Inspired Elements from CaseGen:**
- Clean, professional B2B SaaS aesthetic
- Strong visual hierarchy with clear CTAs
- Video/animation showcasing AI agents in action
- Dashboard screenshots demonstrating real functionality
- Social proof through testimonials
- Comprehensive FAQ section
- Feature-focused sections with visual demonstrations
- Process/implementation timeline
- Dark navy blue as primary brand color

**ODUEO Brand Adaptation:**
- Emphasize "journey" metaphor through design
- Balance innovation with legal industry professionalism
- Focus on transformation narrative (manual → automated)
- Highlight ROI and measurable outcomes

---

## Color Palette & Visual System

### Primary Colors
- **Intelligence Blue:** #0F172A (primary backgrounds, headers)
- **Neural Purple:** #8B5CF6 (accents, CTAs, highlights)
- **Automation Cyan:** #06B6D4 (secondary accents)
- **Cloud White:** #F8FAFC (backgrounds, cards)
- **Slate Gray:** #64748B (body text, descriptions)

### Typography
- **Primary Font:** Inter (sans-serif)
- **Headings:** Bold, large scale (48-72px for H1)
- **Body:** 16-18px for readability
- **Hierarchy:** Clear size differentiation between heading levels

## Key Design Patterns

### Cards
- Border radius: 12-16px
- Subtle shadow: 0 4px 6px rgba(0, 0, 0, 0.1)
- Padding: 32px
- Hover: lift effect (transform: translateY(-4px))

### Buttons
**Primary:**
- Background: Neural Purple (#8B5CF6)
- Text: White
- Padding: 16px 32px
- Border radius: 8px
- Hover: darken + scale(1.05)

**Secondary:**
- Outline: 2px solid current color
- Text: Intelligence Blue
- Background: transparent
- Hover: fill background

### Spacing Scale
- Section vertical padding: 80-120px
- Element spacing: 16px, 24px, 32px, 48px, 64px
- Container max-width: 1200-1400px
- Grid gaps: 24-32px

### Animations
- Page load: fade in + slide up
- Hover states: 0.2s ease
- Scroll animations: elements fade/slide into view
- Video previews: smooth play on hover
- Stats: counter animation on view

---

## Responsive Breakpoints

- **Desktop:** 1200px+
- **Tablet:** 768px - 1199px
- **Mobile:** < 768px

**Mobile Optimizations:**
- Stack columns vertically
- Larger tap targets (min 44x44px)
- Simplified navigation (hamburger menu)
- Reduce text size slightly
- Ensure videos work on mobile (touch to play)
- Condense spacing appropriately

---

## Performance Considerations

### Optimization
- Lazy load images below fold
- Use WebP format for images with fallbacks
- Minimize animation JavaScript
- Compress videos heavily (or use YouTube/Vimeo embeds)
- Critical CSS inline
- Defer non-critical JavaScript

### Loading Strategy
- Hero section loads first
- Progressive image loading
- Video posters as thumbnails
- Skeleton screens for content

---

## Accessibility

### Requirements
- WCAG 2.1 AA compliance minimum
- Proper heading hierarchy (H1 → H2 → H3)
- Alt text for all images
- ARIA labels for interactive elements
- Keyboard navigation support
- Sufficient color contrast (4.5:1 text, 3:1 UI)
- Focus indicators visible
- Screen reader friendly

---

## Content Guidelines

### Voice & Tone
- Professional but approachable
- Focus on outcomes, not features
- Use "you" and "your" (direct address)
- Avoid jargon; explain when necessary
- Emphasize transformation and ROI
- Balance innovation with reliability

### Messaging Principles
- Lead with benefits, not technical specs
- Quantify results where possible (hours saved, % increase)
- Address pain points explicitly
- Use social proof strategically
- Maintain legal industry credibility
- Position as partner, not just software

## Technical Stack Recommendations

### Frontend
- **Framework:** React or Next.js
- **Styling:** Tailwind CSS (matches clean utility approach)
- **Animations:** Framer Motion or GSAP
- **Icons:** Lucide React or Heroicons

### Video/Media
- **Hosting:** Vimeo or YouTube (private)
- **Formats:** MP4 (H.264), WebM
- **Thumbnails:** High-quality posters

### Analytics
- Google Analytics 4
- Hotjar or similar (heatmaps, recordings)
- Conversion tracking on CTAs

- **Demo Request Conversion Rate:** Target 3-5%
- **Time on Site:** Target 2+ minutes
