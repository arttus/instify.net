## Document Format & Style Guidelines

### For Consistency Across All Documents:

**Structure:**
- Clear hierarchical headings
- Short paragraphs (2-4 sentences)
- Bullet points for lists
- Bold for emphasis on key points
- Tables for comparisons

**Tone:**
- Professional but approachable
- Confident without being arrogant
- Educational, not sales-y in RAG docs
- Address concerns directly
- Use "you" and "your" when appropriate

**Content Guidelines:**
- Start with executive summary/overview
- Use examples liberally
- Include specific numbers/data when possible
- Address the "why" not just the "what"
- End sections with key takeaways

**Legal Language:**
- Be careful with guarantees
- Use "typically," "generally," "most firms"
- Include appropriate disclaimers
- Avoid promising specific outcomes
- Emphasize client control and customization
