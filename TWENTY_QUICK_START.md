# Twenty CRM - Quick Start Guide

## 🚀 Deploy in 3 Steps

### Step 1: Generate Secrets & Environment
```bash
./setup.sh dev
```
This generates all required secrets including `TWENTY_APP_SECRET` and `TWENTY_DB_PASSWORD`.

### Step 2: Start All Services
```bash
docker-compose -f docker-compose.yml -f docker-compose.dev.yml up -d
```

### Step 3: Access Twenty
Open your browser to: **http://localhost:3002**

---

## 📋 What Gets Deployed

| Service | Port | Purpose |
|---------|------|---------|
| **twenty-server** | 3002 | CRM API & Web UI |
| **twenty-worker** | - | Background jobs |
| **PostgreSQL** | 5432 | Database (shared) |
| **Redis** | 6379 | Cache & queues (shared) |
| **Nginx** | 80 | Reverse proxy |

---

## 🛠️ Common Commands

```bash
# Restart Twenty services
docker-compose restart twenty-server twenty-worker

# View Twenty server logs
docker-compose logs -f twenty-server

# View Twenty worker logs
docker-compose logs -f twenty-worker

# Connect to Twenty database
docker-compose exec postgres psql -U twenty -d twenty

# Stop all services
docker-compose down

# Stop only Twenty
docker-compose stop twenty-server twenty-worker
```

## 🔐 Environment Variables

Key variables in `.env`:

```ini
TWENTY_DB_USER=twenty
TWENTY_DB_PASSWORD=<auto-generated>
TWENTY_DB_NAME=twenty
TWENTY_APP_SECRET=<auto-generated>
TWENTY_SERVER_URL=http://localhost:3002
TWENTY_LOG_LEVEL=debug
```

## ⚠️ Troubleshooting

### Services won't start?
```bash
docker-compose logs twenty-server
docker-compose logs twenty-worker
```

### Port 3002 already in use?
Edit `docker-compose.dev.yml` and change:
```yaml
ports:
  - "3003:3000"  # Use 3003 instead
```

### Database connection error?
```bash
# Check database exists
docker-compose exec postgres psql -U postgres -l | grep twenty

# Check database is accessible
docker-compose exec postgres psql -U twenty -d twenty -c "SELECT 1"
```

### Worker not processing jobs?
```bash
# Check Redis connection
docker-compose exec redis redis-cli ping

# Check worker logs
docker-compose logs -f twenty-worker
```
