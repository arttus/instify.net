## 🚀 Deployment Steps

### Step 1: Generate Secrets
```bash
./setup.sh dev
```
This creates `.env` with all required secrets.

### Step 2: Verify Environment
```bash
# Check .env was created
ls -la .env

# Verify TWENTY variables
grep TWENTY .env
```

### Step 3: Start Services
```bash
docker-compose -f docker-compose.yml -f docker-compose.dev.yml up -d
```

### Step 4: Wait for Services
```bash
# Wait 30-60 seconds for services to start
sleep 60

# Check status
docker-compose ps
```

### Step 5: Verify Health
```bash
# Check Twenty server
curl http://localhost:3002/health

# Check all services
docker-compose ps
```

```
Open browser to: http://localhost:3002
```

## 🆘 Troubleshooting

| Issue | Solution |
|-------|----------|
| Services won't start | `docker-compose logs twenty-server` |
| Port 3002 in use | Change port in `docker-compose.dev.yml` |
| Database error | `docker-compose exec postgres psql -U twenty -d twenty -c "SELECT 1"` |
| Worker not running | `docker-compose logs -f twenty-worker` |
| Redis error | `docker-compose exec redis redis-cli ping` |
