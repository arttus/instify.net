## 🆘 Quick Troubleshooting

| Issue | Solution |
|-------|----------|
| Services won't start | Check logs: `docker-compose logs twenty-server` |
| Port 3002 in use | Change port in `docker-compose.dev.yml` |
| Database error | Verify: `docker-compose exec postgres psql -U twenty -d twenty -c "SELECT 1"` |
| Worker not running | Check: `docker-compose logs -f twenty-worker` |
| Redis connection error | Test: `docker-compose exec redis redis-cli ping` |
